MINE JAPAN — NEW WEB STARTER

This is the NEW Mine Japan course shell, separate from the old Japaneseeeee implementation.

Files:
- index.html       main page
- style.css        Japanese notebook / scrapbook UI
- script.js        routing, progress, unlocks, lesson rendering
- lessons-data.js  lesson content extracted from the previous 300-lesson content set

Features:
- Start -> Course -> Lesson flow
- Lesson 1 unlocked by default
- Sequential lesson unlocking
- localStorage progress persistence
- Course progress percentage
- Lesson practice interaction
- Responsive mobile-first layout
- Pastel Japanese notebook visual direction

Open index.html directly or deploy the folder to GitHub Pages.
